# 🏫 Sistema Avanzado de Control de Asistencia QR - Panel Académico Pro

Aplicación web institucional desarrollada con **HTML5, CSS3 y JavaScript Vanilla** para la gestión y registro inteligente de asistencias estudiantiles mediante códigos QR.

## 🚀 Funcionalidades Avanzadas
- 📷 **Escáner en Vivo:** Lectura continua con cámara web o cámara móvil mediante `html5-qrcode`.
- ⚡ **Asistencia Detección Instantánea:** Retroalimentación visual inmediata y validación de registros duplicados en el mismo día.
- 🔔 **Retroalimentación Auditiva:** Tonos sintéticos diferenciados para escaneo exitoso o advertencias (Web Audio API).
- 📊 **Exportación a Excel / CSV:** Descarga del historial completo o filtrado por fechas en formato `.csv`.
- 🔍 **Buscador en Tiempo Real:** Filtrado rápido de estudiantes por nombre o código.
- 🖨️ **Carnet Digital Imprimible:** Modal con vista previa estilizada del carnet listo para impresión directa o guardado en PDF.
- 💾 **Persistencia de Datos:** Almacenamiento local automático mediante `localStorage`.

## 🛠️ Tecnologías Utilizadas
- HTML5 / CSS3 (Diseño responsivo, Grid & Flexbox, Plus Jakarta Sans Font)
- JavaScript (Vanilla ES6)
- QRCode.js CDN (Generación de código QR)
- Html5-Qrcode CDN (Lectura de cámara)
